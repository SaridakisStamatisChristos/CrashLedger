# Code of conduct

We want technical discussions to be respectful, constructive, and evidence-based. Treat contributors and users professionally regardless of experience or background. Disagreement is welcome; personal attacks, harassment, discriminatory insults, intimidation, and publishing someone else's private information are not.

Keep feedback specific to code, assumptions, tests, and documented behavior. Do not put security exploit details, credentials, or private incident material in public issues. Maintainers may edit, lock, or close abusive discussions and may restrict participation for repeated violations.

For conduct concerns, contact the repository maintainer privately via their public GitHub profile or GitHub's private reporting options when available. Do not post sensitive personal information in a public discussion. This policy applies to project-owned discussion spaces and does not imply an external enforcement organization.
