# Getting support

CrashLedger is an early open-source CLI, not a hosted service or paid support product. For usage, start with [README](README.md), [scenario format](docs/SCENARIO_V1.md), [the correctness contract](docs/CORRECTNESS_CONTRACT.md), and [evidence format](docs/EVIDENCE_SCHEMA.md).

For reproducible nonsecurity bugs, open a [bug report](.github/ISSUE_TEMPLATE/bug_report.yml) with version, OS, expected/actual exit codes, and sanitized logs. For feature proposals, open a [feature request](.github/ISSUE_TEMPLATE/feature_request.yml) explaining the correctness hypothesis and falsification test.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md), not a public issue. Community assistance and response times are best effort; no response SLA or production support is implied.
